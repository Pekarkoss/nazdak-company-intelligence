## 💻 Kurulum ve Çalıştırma Komutları (Terminal / Git Bash)

Projeyi yerel ortamınızda ayağa kaldırmak, veritabanı inşasını (migration) gerçekleştirmek ve geliştirme sunucusunu başlatmak için aşağıdaki adımları sırasıyla Git Bash veya tercih ettiğiniz terminalde çalıştırınız.

### 1. Projeyi Klonlama ve Bağımlılıkları Kurma
```bash
# Proje reposunu yerel ortamınıza klonlayın
git clone [https://github.com/Pekarkoss/nazdak-company-intelligence.git](https://github.com/Pekarkoss/nazdak-company-intelligence.git)

# Proje dizinine giriş yapın
cd nazdak-company-intelligence

# Gerekli Node.js bağımlılıklarını (dependencies) yükleyin
npm install
