# NASDAQ Company Intelligence Dashboard

Smartinfo / Ekofin değerlendirme projesi için hazırlanmış finansal veri analiz platformu.

## Teknolojiler
- **Backend:** Node.js, TypeScript
- **Frontend:** React / Next.js, TypeScript
- **Veritabanı:** PostgreSQL
- **Veri Sağlayıcı:** Alpha Vantage (ADR 001)

## Proje Yapısı
- `apps/web`: Frontend uygulaması
- `apps/api`: Backend uygulaması
- `docs/`: Mimari kararlar (ADR) ve veri sözlüğü
